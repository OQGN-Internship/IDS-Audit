{% icon "info" %}These rules decide how {{ report.name }}'s files are read, and what counts in its figures. They're rules version {{ version.version }}. Every file is read with the version in force when it's received, and keeps it, so each upload's page says which version it was read with. A change makes a new version, which applies only to files received after it.{% if not can_change %} Only a fixed administrator can change them: ask one when a file needs a rule changed.{% endif %}

Before the report's first upload, check

  1. Header names. Open the export, and compare its column headers with the header names below. A header that isn't listed isn't found, so add it to its field.
  2. Date order. See how the export writes a date such as 3 April: 03.04.2026 is day first.
  3. Decimal separator. In a CSV export, see how it writes an amount: 12,400.500 uses a point for its decimals.
  4. Actual spend. Ask which rows are actual spend. If only some are, list their value types.
  5. Mapping rule. Choose it now. It can't change once the report has an open or a committed upload.
