Header names

Which column headers the report recognises for each field. Each sheet's header row is compared with these names, with capitals, spaces and punctuation ignored, so G/L Account and gl account find the same column. The whole cell must match: Amount doesn't find a column headed Amount in USD.

When a sheet has no column for a field it needs, its upload stops at Needs columns, and its uploader picks the column for that one file. Adding the header to its field here makes every later file read on its own. A GL account or cost center column can't be picked, since they're how each sheet is found: add its header here before the upload.
